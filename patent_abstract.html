SmartShelf: An Automated Perishable Inventory Monitoring and Dynamic Markdown Platform for Retail Stores

The present invention discloses SmartShelf, an intelligent retail inventory optimization and waste-reduction platform engineered to dynamically manage perishable goods through a modular, context-aware web architecture. The system comprises a real-time risk evaluation engine configured to compute inventory decay scores from remaining shelf-life hours, stock levels, day weights, and hyperlocal meteorological telemetry retrieved via a weather integration service. A multi-tier dynamic pricing matrix automatically assigns graduated discount strategies, including soft bundles, zero-waste flash markdowns, and weather-triggered emergency sales. An automated marketing generator synthesizes promotional flash posters using client-side graphics rendering with embedded scannable Quick Response codes. An omnichannel storefront subsystem provides catalog availability, interactive cart management, and seamless order fulfillment. The platform is built on a three-tier architecture utilizing an HTML5 and Tailwind CSS responsive interface, a Java Spring Boot backend, and a cloud-hosted PostgreSQL database.
